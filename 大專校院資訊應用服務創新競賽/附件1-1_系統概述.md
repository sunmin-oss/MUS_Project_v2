# 基於 RAG 技術之智慧藥物辨識與用藥管理系統

**英文專題名稱**：Development of an Intelligent Drug Identification and Medication Management System Based on Retrieval-Augmented Generation (RAG)

---

## 一、前言

本系統旨在透過 Retrieval-Augmented Generation (RAG) 結合影像辨識與知識庫檢索，提供民眾與醫療人員快速、正確之藥物辨識與用藥管理建議。團隊已將原始碼公開於 GitHub（https://github.com/sunmin-oss/MUS_Project_v2.git），並鼓勵採用 Hugging Face 平台之開源模型與資料集以利重現研究成果與社群回饋。

## 二、創意描述

系統結合手機拍照上傳之藥品影像辨識；辨識結果以向量檢索於本地/雲端知識庫中找出藥品標示、使用說明、禁忌與相互作用，再由生成式模型整合成可讀的用藥建議。RAG 流程同時回傳來源片段與相似度分數，提升解釋性與可靠度，並方便專業人員審核。

## 三、系統功能簡介

- 圖像辨識：使用深度學習模型（ResNet、MobileNet 或輕量化模型）辨識藥品外觀與外盒文字。
- 向量檢索（RAG）：以 Sentence-BERT 類模型產生 embedding，透過 FAISS/向量索引執行相似度檢索並回傳證據片段。
- 生成回覆：使用開源/商用 LLM 將檢索到的證據整合並產生可閱讀之用藥建議（並附檢索來源）。
- 用藥管理：建立用藥清單、服藥提醒、服藥紀錄與副作用回報。
- 審核與溯源：每次建議附來源、相似度與原始段落，供藥師或醫療人員驗證。

## 四、系統特色

- 可解釋性：RAG 使生成內容可以回溯到來源文本，降低虛假資訊風險。
- 邊緣/雲端混合：影像預處理與初步分類可於裝置端執行，敏感資訊得以留存本地。
- 開源導向：原始碼公開於 GitHub，模型與資料若採用 Hugging Face，將註明模型/資料集來源，鼓勵社群檢視與回饋（可獲加分）。
- 支援無障礙：介面與說明支援大字顯示與語音輸出，縮短數位落差。

## 五、系統開發工具與技術

- 原始碼託管：GitHub — https://github.com/sunmin-oss/MUS_Project_v2.git
- 模型與資料：鼓勵使用 Hugging Face（若採用之模型或資料集，請於提交時註明名稱與版本）。
- 程式語言／框架：Python、Flask（或 Django）、PyTorch / TensorFlow。
- 向量檢索：FAISS / Annoy（或其他向量索引）。
- RAG 整合：LangChain-like 管線或自製檢索+提示模板流程。
- 部署：Docker 容器化，必要時以 ONNX / TFLite 支援邊緣部署。

### 使用之 AI 工具與範疇（需於系統概述中詳述）

- 影像辨識：訓練或微調之 CNN 模型於藥品外觀檢測。
- 向量檢索：Sentence-BERT 類模型生成 embedding，使用 FAISS/Annoy 做相似度檢索。
- 生成模型（RAG）：使用開源 LLM 或合規商用 API 做證據整合與回覆生成。

## 六、系統使用對象

一般民眾、家庭照護者、藥師、初級照護醫師，亦可作為社福機構或長照中心之輔助工具。

## 七、系統使用環境

支援智慧型手機（iOS/Android）與 Web 平台；伺服器可部署在雲端或院內私有伺服器，並可視需求將敏感處理置於裝置端以維護隱私。

## 八、結語

本系統以 RAG 為核心，強調可追溯之生成式回覆與邊緣/雲端混合部署，採開源實作並公開於 GitHub（見上），期待能提高藥品辨識可及性與用藥安全，縮短偏鄉與弱勢族群之數位落差。
