# 第一章：前言

## 1.1 研究背景

隨著台灣社會高齡化趨勢加劇，根據國家發展委員會推估，台灣已於 2025 年邁入「超高齡社會」，65 歲以上人口佔比超過 20%。年長者因慢性病需求，往往同時服用多種藥物，用藥安全問題日益嚴峻。根據衛生福利部統計，台灣每年因用藥錯誤導致的不良事件數以萬計，其中年長者佔比最高。

現行藥物識別方式主要依賴人工辨認藥品外觀、閱讀藥袋標示或查閱說明書，對於視力退化、認知功能下降的年長者而言，這些方式效率低且容易出錯。市面上雖有部分藥物查詢 App，但多數僅提供文字搜尋功能，缺乏影像辨識能力，且介面設計未針對年長者優化。

## 1.2 問題說明

本研究識別出以下核心問題：

1. **藥物辨識困難**：許多口服藥物外觀相似（白色圓形錠劑佔多數），年長者難以僅憑肉眼區分不同藥物，尤其當藥物脫離原包裝後更難辨別。

2. **傳統辨識方法的局限性**：
   - 本地特徵比對（如 OpenCV）需要大量標註資料與模型訓練，維護成本高
   - 資料庫更新困難，新藥上市後需重新訓練模型
   - 對拍攝角度、光線條件敏感，辨識穩定性不足

3. **AI 幻覺問題**：直接使用大型語言模型（LLM）進行藥物辨識時，模型可能生成不存在的藥物名稱（即「AI 幻覺」現象），導致查詢結果與資料庫不匹配。

4. **用藥管理碎片化**：現有工具僅關注單一環節（辨識或提醒），缺乏整合辨識、用藥管理、安全檢查、AI 諮詢的一站式解決方案。

5. **藥物資訊取得不便**：台灣食品藥物管理署（TFDA）與健保署提供的藥物資料分散於不同網站，使用者需手動查詢，操作複雜。

## 1.3 解決方法概述

本研究開發「藥知道」（MUS — Medicine Understanding System）智慧用藥管理系統，提出以下解決方案：

1. **RAG（檢索增強生成）藥物辨識技術**：結合 Google Gemini Vision API 的多模態辨識能力與本地藥物資料庫，將 4,400+ 筆藥物特徵作為上下文注入 AI 提示詞，讓模型「從已知藥物中選擇」而非盲目猜測，有效解決 AI 幻覺問題，將辨識準確度從約 40% 提升至 85% 以上。

2. **處方箋 OCR 結構化提取**：利用 Gemini 2.5 Flash 多模態模型對藥單照片進行結構化解析，自動提取藥名、劑量、頻率等資訊，並透過「總量驗證演算法」自動偵測並修正 OCR 小數點遺失等常見錯誤。

3. **一站式用藥管理平台**：整合藥物辨識、用藥清單管理、服藥提醒與紀錄、用藥安全檢查（過敏／交互作用）、AI 藥物諮詢等功能，提供從「認識藥物」到「安全用藥」的完整服務鏈。

4. **自動化藥物資料補充系統**：開發 NHI/TFDA 爬蟲系統，自動從衛生福利部健保署與食品藥物管理署網站爬取藥物詳細資訊（適應症、主成分、製造商等），搭配批次更新工具與 7 天快取機制，持續豐富藥物資料庫。

5. **年長者友好介面設計**：採用大字體（18px+）、高對比度配色、簡化操作流程（三步完成）等設計原則，降低年長者使用門檻。

## 1.4 創新所在

本研究的主要創新點包括：

1. **RAG 技術應用於藥物辨識領域**：首次將檢索增強生成技術應用於台灣藥物辨識場景，有效解決 LLM 幻覺問題，實現高準確度的藥物識別。

2. **多層 AI Provider 路由架構**：設計三層鏈式 AI 服務路由（Primary → Secondary → Fallback）搭配熔斷器模式，確保服務高可用性。

3. **處方箋 OCR 總量驗證演算法**：提出基於劑量×頻率×天數的交叉驗證機制，自動偵測並修正 OCR 數值提取錯誤。

4. **四層用藥安全檢查系統**：建立過敏檢查→重複用藥→交互作用→嚴重度分級的四層安全防護機制。

5. **跨平台一站式設計**：單一系統同時支援 Web（SPA）與 iOS 原生 App（Swift/SwiftUI，MVVM 架構，8 個功能模組），整合辨識、管理、安全、諮詢四大功能模組，並以 XCUITest 框架建立 52 個 UI 自動化測試案例確保品質。

## 1.5 實作結果概要

系統已完成全功能實作並部署運行，主要成果包括：

- 整合 **4,419 筆藥物資料**與 **4,776 張藥物實體圖片**
- RAG 辨識模式下資料庫匹配率達 **90%+**
- 支援 **Web SPA**（Capacitor 8 封裝）與 **iOS 原生 App**（Swift/SwiftUI，25 個畫面，8 個功能模組）雙平台
- **52 個 XCUITest 自動化 UI 測試案例**，覆蓋認證、辨識、用藥管理、諮詢、安全檢查、個人設定等功能
- 後台管理系統包含 **25+ 個 API 端點**，覆蓋藥物管理、使用者管理、監控指標、批次更新等完整功能
- 批次更新系統可自動補充 4,400+ 筆藥物的詳細資訊（適應症、主成分等）
- 系統支援 Docker 容器化部署，搭配 Nginx 反向代理、Rate Limiting、JWT 認證等企業級安全機制
