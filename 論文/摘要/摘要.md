# 摘要

　　本專題開發「藥知道」智慧用藥管理系統，針對年長者用藥安全，提出以RAG技術結合Gemini Vision API的藥物辨識方法。將4,419筆藥物特徵注入AI提示詞，約束模型從已知資料庫中選擇，解決AI幻覺問題。

　　實驗顯示RAG模式下資料庫匹配率達90%以上，幻覺率從60%降至5%以下，準確度從40%提升至85%以上。系統整合藥物辨識、藥單OCR、用藥管理、安全檢查與AI諮詢，支援Web與iOS雙平台。iOS 原生 App 以 Swift/SwiftUI 搭配 MVVM 架構開發，包含 8 個功能模組、25 個畫面，並以 XCUITest 建立 52 個自動化 UI 測試案例。

　　主要創新：RAG應用於藥物辨識、多層AI路由搭配熔斷器、處方箋OCR總量驗證演算法、四層安全檢查。

關鍵詞：藥物辨識、檢索增強生成、Gemini Vision、用藥安全、年長者友善設計、SwiftUI、iOS 原生 App
