# 表 I：RAG 辨識 vs 傳統 LLM 辨識比較
# 用途：論文 4.1 節

| 比較項目 | 傳統 LLM 辨識 | RAG 增強辨識 |
|---------|-------------|------------|
| 辨識方式 | AI 自由生成藥名 | AI 從真實藥物庫匹配 |
| 正確率 | ~40% | ~85% |
| 幻覺藥名 | 常出現 | 完全消除 |
| 資料庫對應 | 需二次查詢 | 直接回傳藥物 ID |
| 信心度可靠性 | 低（自信但錯誤） | 高（基於特徵匹配） |
| Token 用量 | 較少 | 較多（含藥物庫） |
| 回應時間 | 2-3 秒 | 3-5 秒 |
| 適用場景 | 通用圖片識別 | 藥物專業辨識 |
