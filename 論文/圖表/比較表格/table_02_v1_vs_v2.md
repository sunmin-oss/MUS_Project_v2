# 表 II：MUS v1 vs MUS v2 系統比較
# 用途：論文 4.2 節

| 比較項目 | MUS v1 (前版) | MUS v2 (本版) |
|---------|-------------|-------------|
| AI 辨識模型 | Google Cloud Vision | Gemini 2.5 Flash |
| 辨識技術 | 純 LLM 辨識 | RAG 檢索增強辨識 |
| 藥物資料庫 | ~500 筆 | 4,420 筆 |
| 藥物圖片 | 無 | 4,776 張 |
| 處方箋 OCR | 不支援 | 9 欄位結構化提取 |
| AI 備援機制 | 無 | 三層路由 + 熔斷器 |
| 用藥安全檢查 | 無 | 四層安全檢查 |
| 使用者認證 | 無 | JWT + bcrypt |
| 多平台 | 僅 Web | Web + iOS |
| 後台管理 | 無 | 完整 Admin Panel |
| 資料更新 | 手動 | 自動爬蟲批次更新 |
| 用藥提醒 | 無 | 排程提醒 + 服藥追蹤 |
| AI 諮詢 | 無 | Gemini 藥物諮詢 |
| 藥局定位 | 無 | Google Maps API |
