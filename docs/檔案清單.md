## 🚀 快速開始

### 方式 1: 最簡單 (Windows)

```batch
# 1. 進入 MUS2 目錄
cd d:\大學\專題\MUS2

# 2. 雙擊 "啟動系統.bat"
# 系統將自動配置並啟動

# 3. 打開瀏覽器訪問
# http://localhost:5000
```

### 方式 2: 命令行（所有平台）

```bash
# 1. 進入 MUS2 目錄
cd MUS2

# 2. 複製環境檔案
cp .env.example .env

# 3. 編輯 .env 填入 API 密鑰

# 4. 安裝依賴
pip install -r requirements.txt

# 5. 啟動系統
python main.py

# 6. 訪問 http://localhost:5000
```

### 方式 3: Docker

```bash
cd MUS2

# 編輯 .env 或 docker-compose.yml
# 填入 API 密鑰

# 啟動
docker-compose up -d

# 訪問 http://localhost:5000
```

## 📞 常見問題快速解答

### Q: API 密鑰哪裡取得？
**A:** 
- **Google Vision:** https://console.cloud.google.com/
- **Claude API:** https://www.anthropic.com/

### Q: 可以離線使用嗎？
**A:** 不能。系統必須連接到 Vision API 進行識別。但本地資料庫查詢在離線時仍然可用。

### Q: 可以自訂資料庫嗎？
**A:** 可以。複製一個新的 SQLite 資料庫並按照 drug_database.py 中的結構修改。

### Q: 可以部署到哪些平台？
**A:** 任何支持 Python/Flask 的平台：
- 本地伺服器
- AWS/Azure/Google Cloud
- Vercel (前端) + Render (後端)
- Heroku
- 個人 VPS

### Q: 如何支持更多語言？
**A:** 修改 vision_api_google.py 中的提示詞，讓 API 回傳其他語言。
