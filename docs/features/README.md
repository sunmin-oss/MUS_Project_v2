## 共通原則

1. **安全紅線優先**：涉及用藥安全的基本警示功能永遠免費
2. **法規敏感字眼避免**：對外文案使用「藥師諮詢」、「用藥資訊」，避免「診斷」「處方」
3. **使用者人工確認**：所有 AI/OCR 自動產出內容寫入用藥清單前必須使用者確認
4. **個資加密**：用藥、過敏、處方箋等敏感資料須加密存放
5. **稽核可追溯**：所有安全警示與使用者回應須記錄日誌

## 狀態定義

- **Draft**：規劃中，內容可變動
- **Reviewed**：經內部討論定案
- **In Development**：開發中
- **Released**：已上線

目前所有 spec 狀態為 **Draft**，待後續討論定 Phase 與排程。
