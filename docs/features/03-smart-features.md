# Feature Spec 03：智慧化功能

> 狀態：規劃中（Draft）
> 分類：智慧化功能
> 對應變現：地圖功能免費；庫存比價列入長期目標

---

## 1. 功能總覽

提供使用者「在哪裡買藥」與「何時該補貨」的決策輔助，降低慢性病患者用藥中斷的風險。

包含子功能：
1. 藥局地圖（Pharmacy Map）
2. 庫存查詢（Stock Query）— 長期目標
3. 價格比較（Price Comparison）— 長期目標
4. 藥品快用完提醒（Refill Reminder）

---

## 2. 目標使用者

- 慢性病患者需要定期補藥
- 旅遊/出差在外地需要找藥局
- 想比價省錢的使用者（指示藥/OTC）

---

## 3. 使用者故事

- US-3.1：身為使用者，我想找附近正在營業的藥局，看地圖、電話、營業時間。
- US-3.2：身為使用者，我希望 App 在我的藥快吃完前 3 天提醒我去領藥。
- US-3.3：（Phase 2）身為使用者，我想查詢哪家藥局有我要的藥品在售。
- US-3.4：（Phase 2）身為使用者，我想比較不同藥局指示藥的價格。

---

## 4. 子功能規格

### 4.1 藥局地圖（MVP）

| 項目 | 內容 |
|---|---|
| 資料來源 | Google Maps Places API + 衛福部「健保特約藥局」開放資料 |
| 顯示資訊 | 名稱、地址、電話、營業時間、是否健保特約、是否 24h |
| 搜尋 | 依距離、營業中、健保特約篩選 |
| 操作 | 導航（接 Google/Apple Maps）、撥打電話、加入最愛 |
| 進階 | 顯示「目前是否營業中」（依當下時間判斷）|

### 4.2 藥品快用完提醒

**計算邏輯**：
```
剩餘天數 = (目前庫存數量) / (每日服用次數 × 每次劑量)
```

- 使用者建立藥品時輸入「初始庫存數量」
- 每次標記服藥自動扣減
- 剩餘 N 天時推播提醒（N 預設 3，可調）
- 提醒內容包含：「快用完的藥」+「最近的藥局」深連結

### 4.3 庫存查詢（Phase 2 — 長期目標）

⚠️ **挑戰**：
- 台灣藥局無公開庫存 API
- 需逐家談合作（成本高）或爬蟲（法律風險）

**可能方案**：
- 與藥局 POS 系統商合作（如：杏一、康是美等連鎖）
- 與健保署合作（理想但機會低）
- 群眾外包（使用者回報）

**Phase 2 不實作，僅在 spec 中保留設計空間。**

### 4.4 價格比較（Phase 2 — 長期目標）

- 僅適用 OTC / 指示藥（處方藥定價受規範）
- 同上，需與藥局合作或爬蟲
- 可先提供「常見藥品建議售價」（衛福部公告）

## 5. 資料模型（草案）

```
Pharmacy
 ├─ id, name, address, lat, lng
 ├─ phone, hours[], is_24h
 ├─ is_nhi_contracted (健保特約)
 └─ data_source (google / nhi_open_data)

Inventory (Phase 2)
 ├─ pharmacy_id, drug_id
 ├─ in_stock, price
 └─ updated_at

UserFavoritePharmacy
 └─ user_id, pharmacy_id
```

## 6. 變現分層

| 子功能 | 免費版 | 付費版 |
|---|---|---|
| 藥局地圖 | ✅ 全開放 | ✅ |
| 藥品快用完提醒 | ✅（綁定提醒功能數量限制）| ✅ 無限 |
| 庫存查詢 | ❌（Phase 2 上線後評估）| ✅ |
| 價格比較 | ❌ | ✅ |

> 藥局地圖刻意全開放，因為這是「導流」入口，可作為未來與藥局合作的籌碼。

---

## 7. 技術考量

- 地圖元件：Capacitor 環境下用 Google Maps SDK 或 Mapbox
- 衛福部開放資料：https://data.gov.tw/dataset/6122（健保特約醫事機構）
- 定位權限：需明確告知使用者用途
- 離線快取：使用者最愛藥局可離線查看

---

## 8. 風險與相依

- **資料新鮮度**：衛福部資料更新頻率不一，需定期同步
- **API 成本**：Google Places API 有 quota，需評估成本
- **爬蟲法律風險**：庫存/價格爬蟲若採用，須先審核合法性
- **依賴**：藥品快用完提醒需 spec 01 的用藥資料模型

---

## 9. 驗收條件（DoD）

- [ ] 可定位並顯示半徑 N 公里內的藥局
- [ ] 篩選條件正常運作（營業中 / 健保特約 / 24h）
- [ ] 導航、撥打、加入最愛操作流暢
- [ ] 藥品庫存能依服藥紀錄自動扣減
- [ ] 補貨提醒能在剩餘 3 天時觸發推播
