# Feature Spec 01：個人用藥管理

> 狀態：規劃中（Draft）
> 分類：個人用藥管理
> 對應變現：部分功能付費（見「變現分層」）

---

## 1. 功能總覽

讓使用者建立並維護自己（與家人）的用藥資料，並透過提醒、紀錄、文件匯入/匯出，協助長期管理慢性病用藥與短期處方治療。

包含子功能：
1. 用藥提醒（Medication Reminder）
2. 服藥記錄追蹤（Adherence Tracking）
3. 處方箋 OCR 自動匯入（Prescription OCR Import）
4. 用藥歷史匯出 PDF（Medication History Export）
5. 家庭成員管理（Family Profiles）

---

## 2. 目標使用者

- 慢性病患者（高血壓、糖尿病、心血管疾病等）長期服藥
- 同時看多個科別、用藥複雜的使用者
- 幫長輩或孩童管理用藥的照顧者
- 短期服藥但容易忘記的使用者

---

## 3. 使用者故事（User Stories）

- US-1.1：身為慢性病患者，我希望 App 在每次服藥時間推播通知，避免漏服。
- US-1.2：身為使用者，我希望點一下就能標記「已服用」或「漏服」，產生用藥紀錄。
- US-1.3：身為使用者，我希望拍照處方箋，App 自動辨識藥名、劑量、頻率並建立提醒。
- US-1.4：身為使用者，我希望匯出近 N 個月的用藥紀錄成 PDF，回診時給醫師看。
- US-1.5：身為照顧者，我希望在同一個 App 內管理父母與小孩的用藥，分別查看與設定提醒。

---

## 4. 子功能規格

### 4.1 用藥提醒

| 項目 | 內容 |
|---|---|
| 設定項目 | 藥名、劑量、單位、服用時間（多筆）、頻率（每日/每週/隔日/週期）、餐前餐後、起訖日期 |
| 提醒通知 | iOS / Android 本地推播；可重複提醒（snooze） |
| 操作 | 通知上可直接「已服用 / 延後 / 略過」 |
| 進階 | 同時間多筆藥品合併通知（避免騷擾） |

### 4.2 服藥記錄追蹤

- 每次提醒回饋（已服 / 漏服 / 略過 / 延後 X 分鐘服用）寫入紀錄
- 提供「服藥日曆」視圖，顏色標示狀態
- 提供「服藥順從率（adherence rate）」統計
- 支援手動補登紀錄

### 4.3 處方箋 OCR 自動匯入

- 拍照或從相簿選取處方箋
- 復用既有 vision API（Claude / Gemini / Google）
- 辨識欄位：藥名、劑量、頻率、天數、用法（口服/外用）、開立日期、醫師、醫療院所
- 辨識結果以「可編輯草稿」呈現，使用者確認後寫入用藥清單
- 與既有藥品資料庫比對，若藥名相符自動補齊成分、注意事項
- 與安全性功能（spec 06）串接：匯入時自動檢查交互作用、過敏、重複用藥

### 4.4 用藥歷史匯出 PDF

- 可選範圍：最近 1 個月 / 3 個月 / 半年 / 自訂
- 內容：用藥清單、服藥紀錄、順從率、過敏紀錄、處方來源
- 格式：A4 PDF，含 QR Code（可選，供醫師掃描快速匯入）
- 多語：中文 / 英文

### 4.5 家庭成員管理

- 模式採「**同帳號多 Profile**」（MVP），未來可擴充為子帳號
- 每個 Profile 獨立：基本資料、用藥清單、提醒、紀錄、過敏史
- 切換 Profile 時 UI 明顯標示「目前查看：XXX」避免操作錯誤
- Profile 數量上限見變現分層

---

## 5. 資料模型（草案）

```
User
 └─ Profile (本人 / 家人)
      ├─ basicInfo (姓名, 生日, 性別, 體重, 過敏史)
      ├─ Medications []
      │    ├─ drug_id (對應 drug_database)
      │    ├─ dosage, unit
      │    ├─ schedule (時間, 頻率)
      │    ├─ start_date, end_date
      │    └─ source (manual / ocr / prescription)
      ├─ Reminders []
      ├─ AdherenceLogs [] (時間, 狀態)
      └─ Prescriptions [] (OCR 來源原圖, 解析結果)
```

## 6. 變現分層

| 子功能 | 免費版 | 付費版 |
|---|---|---|
| 用藥提醒 | 最多 3 種藥品 | 無限 |
| 服藥記錄保存 | 近 7 天 | 無限歷史 |
| 處方箋 OCR | 每月 1 次 | 無限 |
| PDF 匯出 | ❌ | ✅ |
| 家庭成員 Profile | 1（本人） | 最多 6 人 |

---

## 7. 技術考量

- 推播：iOS APNs / Android FCM；本地排程通知為主，減少伺服器負擔
- OCR：復用既有 `vision_api_*.py`；新增「處方箋解析」prompt 模板
- PDF：可採 `reportlab` 或 `WeasyPrint`（Python 後端產生）
- 時區：所有提醒時間以使用者裝置時區為準，伺服器存 UTC

---

## 8. 風險與相依

- **法規**：處方箋影像為個資/病歷，須遵守 PDPA；建議影像不上傳雲端，僅解析結果上傳（或本地保存）
- **依賴**：需先有 spec 06（安全性）資料庫骨架才能完整實現 OCR 匯入時的警示
- **準確性**：OCR 辨識誤差可能造成劑量錯誤，**必須要求使用者人工確認**才寫入

---

## 9. 驗收條件（DoD）

- [ ] 可建立 / 編輯 / 刪除藥品提醒
- [ ] 推播在指定時間正確觸發，可標記服藥狀態
- [ ] 服藥日曆可正確顯示 30 天紀錄與順從率
- [ ] 處方箋 OCR 成功率 ≥ 80%（常見字體與清晰照片）
- [ ] PDF 可正確匯出，包含完整用藥資訊
- [ ] 多 Profile 切換無資料混淆
