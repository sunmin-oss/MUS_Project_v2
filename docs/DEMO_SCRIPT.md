# 藥知道 Demo 影片腳本

> 競賽版本 v1.0.0-beta｜錄製環境：iPhone 16 Pro 模擬器（iOS 18）

## 總時長目標：3–5 分鐘

---

## 開場（0:00–0:20）
- 顯示 App Icon，說明「藥知道」是專為長者設計的智慧用藥管家
- 進入 App，展示 Tab Bar 4 大功能

## Flow 1：藥品辨識（0:20–1:00）
步驟：
1. 點「首頁」→「拍照辨識藥物」
2. 選「從相簿選取」→ 選取測試藥品圖片
3. 展示影像預處理動畫
4. 展示辨識結果（普拿疼 88%）
5. 點進藥品詳情 → 顯示藥品資訊 + 安全警示 banner
6. 返回，展示辨識歷史已記錄

## Flow 2：掃描處方箋（1:00–1:30）
步驟：
1. 首頁 →「掃描處方箋」
2. 展示 OCR 草稿確認頁（可編輯）
3. 按「全部加入用藥清單」

## Flow 3：個人用藥管理（1:30–2:30）
步驟：
1. 切換「用藥」Tab
2. 展示 Profile Switcher（我本人 / 媽媽 / 爸爸）
3. 點「+」新增藥品 → 填寫表單（藥名、劑量、提醒時間）
4. 儲存後展示安全檢查結果
5. 點日曆圖示 → 展示服藥日曆（Swift Charts 圓柱圖）
6. 展示順從率統計

## Flow 4：附近藥局（2:30–3:15）
步驟：
1. 首頁 →「附近藥局」
2. 展示地圖 + 藥局標記
3. 切換到「列表」Tab，開啟「24小時」篩選
4. 點藥局 → 展示詳情（mini 地圖、導航按鈕）
5. 加入最愛

## Flow 5：用藥安全設定（3:15–4:00）
步驟：
1. 切換「我的」Tab
2. 展示字體大小切換（小→大，展示長者友善）
3. 點「安全與健康」→「過敏清單」，展示新增過敏藥品
4. 點「健康狀態」，切換慢性病 toggle
5. 返回展示 Demo 模式切換

## 結語（4:00–4:30）
- 展示技術架構簡介（SwiftUI 原生、Protocol-based API、Mock-first）
- 說明後端擴展計畫（Phase 3 API 串接路線圖）
- App Store 上架路線（Phase 4）

---

## 錄製注意事項
- 使用深色模式錄製（較有質感）
- 字體設定：「大」（展示長者友善設計）
- 確保 Demo 模式已開啟（右上角「DEMO」標示）
- 截圖使用淺色模式（App Store 截圖規範）
